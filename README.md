# hw_08_nn_from_scratch_mipt

Домашнее задание hw08_nn_from_scratch по курсу [girafe-ai/ml-course](https://github.com/girafe-ai/ml-course/tree/23f_basic).

- `modules.ipynb` - слои, функции потерь и оптимизаторы на numpy, в том числе Conv2d и MaxPool2d
- `modules.py` - тот же код в виде .py для Контеста
- `main_notebook.ipynb` - сравнение активаций, BatchNorm, SGD и Adam, итоговая модель на MNIST и сравнение с PyTorch
- `test_modules.ipynb` - тесты из задания
